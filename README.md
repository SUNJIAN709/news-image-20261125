A standard-library Python 3.13 program draws one deterministic picture of Wednesday 25 November 2026 for the make.fun bounty. It writes `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` outside the grader).

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Stories are the ones news services reported that day: Tiangong’s first foreign astronaut, new US tariffs and the market slide, strikes on Ukraine’s grid, killings in Sudan and Gaza, the Strait of Hormuz, a List A cricket record, and Pope Leo XIV on COP31.
